# L & E Construction Group — speculative redesign

A concept website for **L & E Construction Group** (Santa Ana / Orange County residential remodeling).

**This is a speculative Novenworks redesign.** L & E Construction Group is not a Novenworks client and did not hire this work. Business marks, the L&E logo, and project photography remain property of their owners. The live business website is [lneconstructiongroup.com](https://www.lneconstructiongroup.com/).

## What this is

Owner-led remodeling, presented with the company’s own kitchen, bathroom, and jobsite photographs, Eric Bernal’s first-party copy, three on-site testimonials, and a verified CSLB license (#1070952, B – General Building, current as of 8 Sep 2026).

The operator brief is at `/outreach` (unlinked, noindex).

## Stack

TanStack Start, React 19, TypeScript, Tailwind CSS v4, Radix/shadcn-style primitives. (The originating build prompt requested Next.js App Router; this environment ships TanStack file routes instead.)

## Local

```bash
npm install
npm run dev
```

Preview binds to `0.0.0.0:8080`. Production build: `npm run build`.

## Facts we will not invent

Revenue, ROI, lead volume, review totals, star ratings, founding date, years in business, warranties, financing, staff size, insurance slogans, or extra service cities beyond first-party copy and on-site testimonials.
